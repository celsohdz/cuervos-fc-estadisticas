# Cuervos FC · Estadísticas

Primera versión del sitio público de resultados y estadísticas de Cuervos FC.

## Vista local

Sirve esta carpeta con cualquier servidor web estático y abre `index.html`.

## Datos publicados

El archivo `data/stats.json` contiene únicamente estadísticas deportivas: temporadas, jugadores y resultados. No se publican fechas de nacimiento, números de cédula ni otros datos personales.

Los escudos de `assets/team-logos/` se obtuvieron de la [página pública de Liga Master Clausura 2026 en CopaFácil](https://copafacil.com/-ihroy) el 18 de septiembre de 2026. Se guardan localmente para que la tabla no dependa de enlaces externos que puedan cambiar.
